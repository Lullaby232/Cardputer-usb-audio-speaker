================================================================
  Cardputer Speaker  ·  M5 Cardputer ADV 免驱 USB 声卡
  版本 v1.5
================================================================

把 Cardputer ADV 插到电脑 USB 口，它就变成一只免驱扬声器：
声音从板载 ES8311 + 功放 + 喇叭出来。Windows / macOS / Linux 都不用装驱动。


----------------------------------------------------------------
一、烧录（只需要一次）
----------------------------------------------------------------

1. 用 USB-C 数据线把 Cardputer 连到电脑（必须能传数据，只能充电的线不行）。

2. 用乐鑫官方工具 ESP32 Flash Download Tool 烧录
   固件\usbspk-v1.5-8MB.bin，地址填 0x0（不是 0x1000）。

     ChipType / WorkMode ..... ESP32-S3 / Develop
     文件 & 地址 ............. usbspk-v1.5-8MB.bin -> 0x0
     SPI SPEED / MODE ........ 80MHz / DIO
     FLASH SIZE .............. 8MB

   命令行方式（已装 esptool）：
     esptool.exe --chip esp32s3 -p COM3 -b 921600 write_flash 0x0 usbspk-v1.5-8MB.bin

3. 烧完拔线，再插回去。

   ！这一步不能省。ESP32-S3 用的是芯片内置 USB-Serial/JTAG，没有把 RTS
     接到复位脚，烧完会停在下载模式，必须拔插一次才会跑新固件。

   屏幕亮起显示「已连接 · 待机」就成功了。


----------------------------------------------------------------
二、电脑端只要做两件事
----------------------------------------------------------------

1. 把输出设备切成「Cardputer Speaker」
   Windows：右下角喇叭图标 -> 展开输出设备列表
   macOS  ：系统设置 -> 声音 -> 输出

2. 系统音量拉到 100%（拉满就是满幅输出，不用留余量）
   觉得吵就在键盘上按 "-" 降本机音量。

第一次插上要等约 2 秒才出声，因为固件要等缓冲攒够 30ms，避免开头"咔"一声。


----------------------------------------------------------------
三、按键与屏幕
----------------------------------------------------------------

按键
     -  /  =        本机软件音量 -/+（32 级）
     [  /  ]        ES8311 模拟增益 -/+ 2dB（-6 ~ +16dB）
     m              静音开关
     G0 短按        静音开关
     G0 长按 3 秒   进入 USB 下载模式（重新烧录用）
     Fn + 方向键    同上（Cardputer 的方向键本身是 Fn 组合键）

屏幕
     L / R          左右声道电平，对数刻度 -48 ~ 0 dBFS
     □ 小方块       CLIP，真的发生数字削波才亮红
     电脑 xx dB     电脑侧音量滑块换算值
     DAC +6dB       ES8311 模拟增益（按 [ ] 调）
     缓冲 xx ms     环形缓冲水位，正常 20 ~ 60ms
     D:136 ok       描述符长度自检，不符会变成红色 BAD

关于电平条发红
     红只代表"到满刻度"，不代表失真。现代音乐母带峰值本来就在 -1 ~ 0 dBFS。
     真失真要盯右边那个 CLIP 方块，它亮红才是样本被截断了。


----------------------------------------------------------------
四、开发过程中遇到的问题与修复
----------------------------------------------------------------

这一节是整份文档最值钱的部分。UAC2 + ESP32-S3 + M5Unified 的组合坑很多，
以下全部是实测踩出来的，按遇到顺序排列。

[1] 烧录显示成功，设备却不启动
    现象：esptool 报 Hash of data verified，但设备停在 ROM 下载模式。
    原因：用的是芯片内置 USB-Serial/JTAG，没有 RTS->EN 连线，
          最后那句 Hard resetting via RTS pin 实际无效。
    结论：硬件限制，只能物理拔插。为了省事，固件加了「长按 G0 三秒写入
          RTC_CNTL_FORCE_DOWNLOAD_BOOT 再重启」的入口，重新烧录不必按住
          BOOT 插线。

[2] 编译通过，但电脑完全看不到音频设备
    原因：编译参数里少了 USBMode，走的是硬件 CDC，TinyUSB 根本没被编进固件。
    修复：FQBN 必须显式带 USBMode=default,CDCOnBoot=default。

[3] 描述符长度自己就对不上
    输入终端是 17 字节不是 18；AudioControl 接口的 bInterfaceProtocol 应为
    0x20（IP 协议 2.0），写 0x00 会被主机忽略。
    屏幕右上角那个 D:136 ok 就是长度自检结果，不符会变红显示 BAD。

[4] Windows 报「设备无法启动（代码 10）」—— 最坑的一条
    现象：设备管理器黄色感叹号，错误代码 10，音频端点不注册。
    排查：先补 IAD（无效）-> 换成 tinyusb 官方 uac2_headset 的宏整份重写
          描述符（仍无效）-> 最后逐字段二分，定位到 bcdUSB = 0x0210。
    根因：bcdUSB >= 0x0210 会让主机去读 BOS 描述符，而 arduino-esp32 内置的
          BOS 是给 CDC/WebUSB 写的，纯音频设备解析失败即判定无法启动。
    修复：改回 ucfg.usb_version = 0x0200，一次枚举成功，Windows 自动挂上
          "USB Audio 2.0" 系统驱动，完全免驱。

[5] 声音小到几乎听不见（约 -42 dB）
    根因：M5Unified 的音量是平方曲线：
              float volume = magnification * (master_volume * master_volume);
          初版用 setVolume(32) 并把 magnification 从默认 16 降到 8，
          相当于满配置的 1/120。
    修复：主音量恢复满量程 255、magnification 恢复 16；再把 ES8311 DAC 音量
          （寄存器 0x32，0xBF = 0dB）做成可调，默认 +6dB。
          单这一项就把响度拉回约 120 倍。

[6] 屏幕一直在闪
    原因：每 80ms 把整块区域 fillRect 再重画文字，SPI 写入不是原子的，
          能看出"先黑一下再亮"。
    修复：所有数值区记住上次画的值，只在变化时重画；一直在变的缓冲水位改成
          "前景色 + 背景色"定宽覆盖写，不整行清屏。

[7] 键盘只有 G0 键有反应
    现象：G0 能静音（走 M5.BtnA 的 GPIO），但 - = [ ] m 全无反应。
    根因：Keyboard.updateKeysState() 只解析已有的键列表，不会去硬件取事件。
          ADV 的键盘是 TCA8418（I2C 扫描、中断驱动），必须先 updateKeyList()
          读事件 FIFO。
    修复：改调 M5Cardputer.update()，它内部 =
          M5.update() + updateKeyList() + updateKeysState()。

[8] 长按 G0 三秒没反应
    原因：靠数 loop 次数计时（++g0_hold > 150），但 loop 里刷屏让周期远大于
          20ms，实际要七八秒才触发。
    修复：改用 millis() 差值判断，与循环速度解耦。

[9] 电平条有规律地一闪一闪
    原因：和屏闪同源 —— 每 80ms 把 200px 宽的条先刷深灰底、再覆盖前景色、
          再重画边框，三趟 SPI 之间能看出明暗跳变。
    修复：改增量绘制。记住上次宽度和颜色，变长只补新增的一小段、变短只擦多出
          的一小段、没变就一个像素都不写。颜色另加迟滞（红 0.98/0.94、
          黄 0.90/0.86），避免阈值附近绿黄来回跳。

[10] 状态行的字盖住了 L 电平条
    现象：「已连接 · 待机 / D:136 ok」压住 L 条，还叠着模糊旧字。
    根因：不是清屏范围太大，而是上一屏残留没清 —— 开机时未连接分支在 y=44 /
          y=60 写了两行诊断文字（"等待主机枚举…"、"desc 136/136"），连上后只清了
          状态行（y20..37），那两行就永远留在屏上，正好被电平条压着。
    修复：加「脏标记」。未连接分支画完置位，已连接分支第一次进来先整块清空
          y20..130，并把电平条/音量/dB/剪波灯的记忆值全部复位强制重画，
          之后才恢复"只清状态行"的轻量刷新。
    经验：局部刷新时，"上一屏残留"比"清屏范围过大"更容易被忽略 —— 任何切入
          另一套布局的分支，离开时都要把整块区域标记为脏。


----------------------------------------------------------------
五、常见问题
----------------------------------------------------------------

问：声音设置里找不到 Cardputer Speaker
答：先看设备管理器有没有黄色感叹号。若显示 "USB Audio 2.0" 且状态正常，
    展开"音频输入和输出"，右键"显示已断开的设备"看看。
    也可能是线只能充电、没有数据线芯。

问：声音偏小
答：系统音量拉到 100%，再按 ] 把 DAC 增益加到 +10 ~ +16dB。再大就开始失真。

问：偶尔有咔哒声 / 爆音
答：把系统音量降到 80 ~ 90%。输入已经是 0dBFS 满幅时，额外模拟增益只会削波。

问：想改回普通 Cardputer 用途
答：直接烧回官方固件或自己的 sketch 即可。本固件不写 NVS、不改持久设置。

问：怎么重新烧录
答：长按 G0 三秒进入下载模式（屏幕显示"进入 USB 下载模式..."），电脑出现
    COM 口后直接烧 0x0，烧完拔插一次启动。

问：自己编译要什么环境
答：esp32 core 3.3.12 / M5Cardputer 1.1.1 / M5Unified 0.2.29 / M5GFX 0.2.36
    开发板设置：ESP32S3 Dev Module，Flash Size 8MB，分区 Huge APP，
    USB Mode 选 TinyUSB（arduino-cli 写 USBMode=default），
    USB CDC On Boot 选 Default（CDCOnBoot=default）。

     arduino-cli compile ^
       --fqbn "esp32:esp32:esp32s3:FlashSize=8M,PartitionScheme=huge_app,USBMode=default,CDCOnBoot=default" ^
       --libraries "<libraries 目录>" --build-path build firmware/usbspk

     生成的 build/usbspk.ino.merged.bin 就是 8MB 整片镜像。
